Rerandomized subsampled trigonometric transforms: the Walsh case

This statement answers the two-round real Walsh case of Problem 5.6 in https://arxiv.org/abs/2602.05394v3. Its probability is a literal uniform finite average over two independent sign assignments and a set of distinct rows. The one intentional proof hole is the declaration that Comparator checks against the complete proof in Solution.lean.

The real sign represented by a bit: zero is +1, one is -1.

The normalized Walsh matrix, with entries n^(-1/2) (-1)^(a dot b).

def hadamard (k : ℕ) : Matrix (Index k) (Index k) ℝ := fun a b => (Real.sqrt (Fintype.card (Index k) : ℝ))⁻¹ * ∏ i, sign ((ZMod.commRing 2).mul (a i) (b i))

The two-round matrix H D_y H D_x; each diagonal entry is a real sign.

def rerandomized {k : ℕ} (x y : Signs k) : Matrix (Index k) (Index k) ℝ := hadamard k * Matrix.diagonal (fun i => sign (y i)) * hadamard k * Matrix.diagonal (fun i => sign (x i))

For every fixed real orthonormal frame in a Walsh space of order 2^k, two independent sign rounds followed by uniform distinct-row sampling give an OSE with probability at least 1-δ. The explicit row budget is at most C(δ) d/ε², independent of the ambient size; thus any fixed 0<δ<1/2 gives the dimension dependence asked for in Problem 5.6.
